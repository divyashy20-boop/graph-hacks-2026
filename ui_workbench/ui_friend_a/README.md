Work only in this folder while the collaboration hold is active.

Create isolated work under:

- `fragments/` — proposed semantic HTML fragments, never a full page copy.
- `styles/` — scoped CSS using the `ugi-a-` prefix.
- `artifacts/` — local screenshots/recordings/logs; never stage these.
- `CHANGE_MANIFEST.md` — required mapping from each artifact to a future
  canonical insertion point.

Owned surfaces: dataset controls, source inspector, relationship verdict,
investigation/review presentation and their state language. Do not implement
graph camera/renderer behavior or guided request/freshness logic here.

Follow UI-010 and `../UI_CONTRACT.md`.
